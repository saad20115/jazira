## Audit status (with active overrides)

Both `pnpm audit --prod` and full `pnpm audit` (including `devDependencies`) exit `0` with `No known vulnerabilities found`.

## Verification protocol
Whenever `pnpm.overrides` or `payload` versions are modified:
1. Save `pnpm audit --prod --json` and `pnpm audit --json` before and after the change, and copy all advisory IDs, severities, ranges, and pre-fix versions directly from those JSON files and `pnpm-lock.yaml`.
2. Run `pnpm install --frozen-lockfile`.
3. Run `pnpm audit --prod` and `pnpm audit` (both must report `No known vulnerabilities found`, exit `0`).
4. Verify schema migration generation and execution (`pnpm payload migrate:status` and `pnpm payload migrate:create`).
5. Run `pnpm test` and `pnpm test:e2e`.
