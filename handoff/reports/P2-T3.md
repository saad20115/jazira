## Done
- **Carried-over minor item from `P2-T1` (`R-17` — `src/fields/slug.ts`, `src/fields/slug.test.ts`, `tests/int/p2-t1-slug.int.test.ts` — `59eb77e`)**:
  - Generalized stale auto-slug detection in `slugField` (`beforeValidate`) to check candidate auto-slugs across both `ar` and `en` source titles (`isStaleAutoSlugCandidate`), so resending a stale `ar`-transliterated or `en`-derived auto-slug during an `en` or `ar` save never locks `slugLocked` or reverts the slug. Verified by unit and real DB integration tests (`stale-payload sequences: resending stale auto-slugs in ar or en saves does not revert or lock the slug (R-14, R-17)`).
- **Limited Lexical RichText factory & server-side AST validator (`src/fields/richText.ts`, `src/fields/richText.test.ts` — `I2`, `I3` — `4db27b4`)**:
  - Created `limitedRichTextField()` and `validateLimitedLexicalState()` enforcing the exact 9 allowed Lexical features (`LIMITED_LEXICAL_FEATURE_KEYS`):
    1. `ParagraphFeature()` (`paragraph`)
    2. `HeadingFeature({ enabledHeadingSizes: ['h2', 'h3', 'h4'] })` (`heading` — `h2`, `h3`, `h4` only; `h1`, `h5`, `h6` rejected)
    3. `BoldFeature()` (`bold`)
    4. `ItalicFeature()` (`italic`)
    5. `UnorderedListFeature()` (`unorderedList` — `listType: 'bullet'`)
    6. `OrderedListFeature()` (`orderedList` — `listType: 'number'`; `check` lists rejected)
    7. `BlockquoteFeature()` (`quote`)
    8. `LinkFeature({ enabledCollections: ['services', 'projects'], fields: ... })` (`link` / `autolink` — custom URLs validated via `I3` (`http:`, `https:`, `mailto:`, `tel:` or single-leading-`/` internal path), internal doc links restricted to `services` and `projects`)
    9. `UploadFeature({ collections: { media: { fields: [] } } })` (`upload` — `relationTo: 'media'` only)
  - Disables inline/block code, strikethrough, underline, subscript/superscript, horizontal rules, tables, custom blocks, raw HTML, and iframes in the editor, and validates the submitted AST recursively in `beforeValidate` so disallowed nodes (`iframe`, `rawHtml`, `script`, `code`, `block`, `horizontalrule`), disallowed heading tags (`h1`, `h5`, `h6`), disallowed text format bitmasks (`~(1 | 2)`), non-`media` uploads, or unsafe link URLs (`javascript:`, `data:`) are rejected with HTTP `400` on both draft (`_status: 'draft'`) and published saves.
- **Custom Admin service icon picker (`src/components/icons/ServiceIcon.tsx`, `src/components/admin/ServiceIconField.tsx` — `4db27b4`)**:
  - Defined `SERVICE_ICON_OPTIONS` for the 10 approved Figma icons from `docs/02-content-model.md` Addendum (`contracting`, `mep`, `fire`, `smart`, `hvac`, `plumbing`, `electrical`, `supply`, `testing`, `maintenance`) with bilingual `ar`/`en` labels and inline SVG paths (`ServiceIcon`).
  - Built client component `ServiceIconField` (`'use client'`) rendering a radio-button grid where each option displays its SVG icon alongside the active UI language label (`ar` / `en`) and code key, registered in `src/app/(payload)/admin/importMap.js`.
- **`services` collection (`src/collections/Services.ts`, `src/payload.config.ts` — `Z1`, `Z2`, `I2` — `4db27b4`, `2b01dce`)**:
