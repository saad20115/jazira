## 5. Security Notes

- `isArabicEnabled` (`src/lib/cms/globals.ts:71`), `isSameOriginAdminReferer` (`src/lib/cms/client.ts:332`), and `isAuthorizedArabicPreviewRequest` (`src/lib/cms/client.ts:356`) run strictly on the server inside `server-only` (`src/lib/cms/client.ts:1`) and `server-only` (`src/lib/cms/globals.ts:1`) modules.
