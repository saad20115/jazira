## What changed
- **`src/app/(frontend)/[locale]/services/[slug]/page.tsx` (`R-60`):**
  - **Root cause:** Exporting `generateStaticParams` on `/[locale]/services/[slug]` caused Next.js to treat pre-rendered slug paths as static routes while the page component and `generateMetadata` invoked dynamic server APIs (`headers()` and `draftMode()`), throwing `DYNAMIC_SERVER_USAGE` on `next start` when prerendered paths were requested or when `generateStaticParams` returned `[]` on an un-published seed database.
  - **Fix:** Removed `generateStaticParams` from `src/app/(frontend)/[locale]/services/[slug]/page.tsx` so the route is dynamically server-rendered on demand (matching `/[locale]/services/page.tsx`), rendering published slugs, returning `notFound()` for unknown or draft-only slugs when anonymous, and supporting draft mode / live preview on `next start`.
- **`src/components/ApprovedMaterialsTable.tsx` & `src/components/ApprovedMaterialsTable.module.css` (`R-61`, `R-64`, `R-65`):**
  - **`R-61`:** Changed the initial selected system tab to `electrical` (`useState<MaterialSystemTab>('electrical')`) and collapsed the initial view to `INITIAL_VISIBLE_ROWS` rows (`isExpanded = false`), rendering `.tableFooter` outside `.tableCard` with the system summary text (`Showing ... electrical items`) and an Outline `"View all ... items →"` button that expands the table when clicked. Clicking `"All systems"` or typing a search query displays all matching rows.
  - **`R-64`:** Replaced undefined CSS custom properties (`--color-border`, `--color-white`, `--color-surface`, `--color-navy-950`, `--color-gold-*`, `--color-text-*`) with the canonical tokens in `src/styles/tokens.css`, adjusted `.section` top block padding and `.headerCopy` gap, placed `.td` before `.colNo`/`.colMaterial`/`.colBrand`/`.colOrigin` without overriding `padding-inline`, and aligned column widths and inline paddings (`colNo`, `colMaterial`, `colBrand`, `colOrigin`) so header and body column starts match the Figma frame (`157:3293`) and `"United States · Saudi Arabia"` stays on a single line.
  - **`R-65`:** Wrapped `{paddedItemNo}`, `{row.description}`, `{brand.name}`, and `{originsText}` in `<bdi>` across both desktop `<table>` cells and mobile stacked cards so Latin text and trailing punctuation inside RTL (`ar`) preserve their LTR character order.
- **`src/app/(frontend)/[locale]/services/page.module.css` & `src/components/ServiceTile.module.css` (`R-62`, `R-63`):**
  - **`R-62`:** Added `display: flex` on `.specialistGridItem` and `block-size: 100%` on `.specialistTile`, with `margin-block-start: auto` on `.linkRow` in `ServiceTile.module.css`, so all cards in each Specialist Services row share equal height with `"Learn more →"` pinned to the bottom edge.
  - **`R-63`:** Tightened `.mainServicesContainer` block gap, `.highlightsList` padding, `.serviceCtaWrap` top padding, and `.serviceCtaWrap` button block padding to match the Figma `02-services` section (`24:1490`).
