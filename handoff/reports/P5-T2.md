## What changed
- **Notification job `notifyQuoteRequest`:**
  - sends to `SALES_INBOX` only;
  - at most 5 attempts with exponential backoff (about an hour);
  - a row lock around the send, so it never sends twice;
  - a scrubbed `emailLastError`, at most 500 characters.
- **Resend notification:** an admin-only endpoint and a button. A conditional claim means a second
  click gets 409.
- **"Mine" filter:** the list filter bar now changes the list through Payload's `useListQuery`.
  The e2e found that a cleared filter came back before; this fixes it.
- **CSV export:**
  - admin only, using the current filter and search;
  - UTF-8 with BOM, formula-safe;
  - no `ipHash`, `userAgent`, `internalNotes` or e-mail fields;
  - each export is logged with the user ID, time and row count.
- **Retention:** a daily job deletes requests older than 24 months. It is a dry run until an
  admin enables `site-settings.quoteRetentionDeleteEnabled`.
- **Scheduler global:** `payload-jobs-stats` is denied to every role (Z1 test).
- **Migration:** `20261111_065443_p5_t2_jobs_retention`.
