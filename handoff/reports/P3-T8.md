## What changed
- **`src/app/(frontend)/[locale]/projects/[slug]/page.tsx` (`R-60`):**
  - **Root cause:** Exporting `generateStaticParams` on `/[locale]/projects/[slug]` caused Next.js to pre-render published project routes as static while the page component and `generateMetadata` invoked dynamic server APIs (`headers()` and `draftMode()`), throwing `DYNAMIC_SERVER_USAGE` on `next start` for pre-rendered routes and returning `500` when `getProjectsPage`/`getHomePage` rejected or when dynamic server APIs ran inside a static page context.
  - **Fix:** Removed `generateStaticParams` and `getPublishedProjectSlugs` from `src/app/(frontend)/[locale]/projects/[slug]/page.tsx` and added `.catch(() => null)` + optional chaining on `getProjectsPage` and `getHomePage`, so `/[locale]/projects/[slug]` is dynamically server-rendered on demand, returning `200` for published slugs, `notFound()` (`404`) for unknown or draft-only slugs when anonymous, and supporting draft mode / live preview on `next start`.
- **`src/app/(frontend)/[locale]/projects/page.tsx` & `src/app/(frontend)/[locale]/projects/page.module.css` (`R-70`, `R-71`, `R-73`, `R-65`):**
  - **Replaced undefined `--color-*` CSS variables:** Replaced all undefined `--color-white`, `--color-surface`, `--color-navy-*`, `--color-gold-*`, `--color-text-*`, `--color-border`, and `--color-glass-*` variables with the canonical tokens in `src/styles/tokens.css`, restoring the opaque white background, shadow, and text color on `.portfolioBadge` (`R-70`).
  - **`R-70`:** Set `.portfolioBadge` dimensions, padding, border-radius (`--radius-2xl`), shadow (`--shadow-who-badge`), and desktop/mobile overhang positioning (`inset-block-start` / `inset-inline-end` on desktop, overhanging bottom inline-end on mobile), and passed `strokeWidth={4} strokeLinecap="round"` to `<CornerBracketIcon>` to match Figma `19:904`.
