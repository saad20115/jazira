### Security Notes

- **`Z4` (`quote-requests` never creatable via REST)**: Enforced at both collection level (`create: () => false` at `src/collections/QuoteRequests.ts:413`) and field level (`create: () => false` on `readOnlyFieldAccess` at `src/collections/QuoteRequests.ts:39` and `workflowFieldAccess` at `src/collections/QuoteRequests.ts:45`).
- **`Z1` & `R-2` (Principle of Least Privilege, Field-Level Immutability & Immutable `createdAt`)**: Anonymous callers receive `403` on all endpoints; editors and admins can read and update only `status`, `assignedTo`, and `internalNotes`; customer fields, `serviceTitle`, system fields, and `createdAt` (across all 10 collections via `withImmutableCreatedAt` at `src/collections/_shared/immutableTimestamps.ts:116`) are immutable via REST/admin even for `admin`; only `admin` can delete (`src/collections/QuoteRequests.ts:415`–`src/collections/QuoteRequests.ts:417`).
- **`D2` & `S4` (No Raw IP Stored; Server-Only Salt)**: `src/lib/ipHash.ts` enforces a runtime browser-bundle guard (`if (typeof window !== 'undefined')` at `src/lib/ipHash.ts:15`) and is blocked from `"use client"` modules at lint time by the custom `local/no-server-in-client` ESLint rule (`eslint-rules/no-server-in-client.mjs:17`, `eslint-rules/no-server-in-client.mjs:46`, `eslint.config.mjs:42`); `QuoteRequests` validates `ipHash` against `/^[a-f0-9]{64}$/` (`src/lib/ipHash.ts:21`) so raw IP addresses can never be stored.
- **`I1` & `R-3` (Defense-in-Depth Validation & Shared Phone Schema)**: `QuoteRequests` validates `name`, `email`, `phone` (normalizing `00` → `+`, requiring `+` for international numbers, rejecting repeated-digit junk, and validating 9 national digits for `+966`/`00966` via `normalizeQuotePhone`, `isValidKsaOrInternationalPhone`, and `quotePhoneSchema` at `src/collections/QuoteRequests.ts:62`–`src/collections/QuoteRequests.ts:120`), `consent === true`, enum memberships (`locale`, `status`, `emailStatus`), and foreign-key existence for `service` (`services`) and `assignedTo` (`users`), and truncates `userAgent` to 300 chars (`src/collections/QuoteRequests.ts:234`), `serviceTitle` to 200 chars (`src/collections/QuoteRequests.ts:250`), and `emailLastError` to 500 chars (`src/collections/QuoteRequests.ts:256`).

### Deviations from Spec

1. **Runtime `typeof window !== 'undefined'` guard + `local/no-server-in-client` ESLint rule in `src/lib/ipHash.ts` (`R-1`)**: Because `src/lib/ipHash.ts` is imported transitively by `src/collections/QuoteRequests.ts` → `src/payload.config.ts`, a top-level `import 'server-only'` statement would throw when running the Payload CLI (`pnpm payload migrate`, `pnpm generate:types`) under Node/`tsx` outside Next.js's `"react-server"` condition (the same constraint documented in `src/env.ts:8`). Instead, `src/lib/ipHash.ts` uses a runtime `if (typeof window !== 'undefined')` guard (`src/lib/ipHash.ts:15`) combined with our custom `local/no-server-in-client` ESLint rule (`eslint-rules/no-server-in-client.mjs:17`, `eslint-rules/no-server-in-client.mjs:46`, `eslint.config.mjs:42`).
2. **Read-only `serviceTitle` snapshot field on `quote-requests` (`R-4`, CTO decision)**: Added `serviceTitle` (`type: 'text'`, `maxLength: 200`, `access: readOnlyFieldAccess`, `admin: { readOnly: true }`) at `src/collections/QuoteRequests.ts:501` so quote history remains readable if a referenced `services` document is later deleted (`service` remains `ON DELETE SET NULL`).
3. **`Users.admin.useAsTitle: 'name'` with `email` fallback (`R-5`, CTO decision)**: Updated `src/collections/Users.ts` (`useAsTitle: 'name'` at `src/collections/Users.ts:196`, `forceSelect: { name: true, email: true }` at `src/collections/Users.ts:181`, and `resolveUserDisplayNameBeforeValidate` / `resolveUserDisplayNameAfterRead` at `src/collections/Users.ts:139`, `src/collections/Users.ts:165`) so `assignedTo` displays the staff member's display name (or email fallback) rather than "بدون عنوان" (Untitled).
