## Revalidation Tags & Paths per Change (`src/collections/Projects.ts:184-306` & `345-360`)

Revalidation runs **only** when a project is published (`_status === 'published'`), unpublished/changed from a previously published state (`previousDoc._status === 'published'`), or deleted (`afterDelete`). Draft creation and draft-to-draft autosaves do **not** trigger revalidation.

| Trigger / Change Event | Cache Tags Invalidated (`safeRevalidateTag`) | Next.js Paths Invalidated (`safeRevalidatePath`) | Source (`file:line`) |
|---|---|---|---|
| **Any publish / update of a published project / unpublish / delete** (Project detail page) | `doc:projects:<slug>`, `doc:projects:<slug>:ar`, `doc:projects:<slug>:en` (plus `<previousSlug>` variants if `slug` changed) | `/ar/projects/<slug>`, `/en/projects/<slug>` (plus `/ar/projects/<previousSlug>`, `/en/projects/<previousSlug>` if `slug` changed) | `src/hooks/revalidate.ts:122-179`, `src/collections/Projects.ts:346-358` |
| **Any publish / update of a published project / unpublish / delete** (Projects listing page) | `collection:projects`, `collection:projects:ar`, `collection:projects:en` | `/ar/projects`, `/en/projects` | `src/hooks/revalidate.ts:116-140`, `src/collections/Projects.ts:346-358` |

## Security Notes

- **Draft isolation (`Z2`)**: `read: publishedOrLoggedIn` ensures anonymous callers only see `_status: 'published'` snapshots on both REST (`/api/projects`, `/api/projects/:id`, `?draft=true`) and Local API (`overrideAccess: false`).
- **Write access (`Z1`)**: `create`, `update`, and `delete` require `isAdminOrEditor`.
- **RichText sanitization (`I2`, `I3`)**: `body` uses `limitedRichTextField` with server-side AST validation and `LinkFeature({ enabledCollections: ['services', 'projects'] })`.
- **Video embed host allowlist (`I4`)**: `videoUrl` enforces `https://` and exact host matching against the 6 allowlisted YouTube/Vimeo hosts (`youtube.com`, `www.youtube.com`, `m.youtube.com`, `youtu.be`, `vimeo.com`, `player.vimeo.com`) on both draft and published saves.
