## Security Notes
- **`Z1` (Explicit Access Control)**: `SiteSettings` (`src/globals/SiteSettings.ts:349`) enforces `read: () => true, update: isAdmin`; `Navigation` (`src/globals/Navigation.ts:224`) enforces `read: () => true, update: isAdminOrEditor`; all 6 page globals wrapped with `withPublishableGlobal` (`src/globals/_shared/publishableGlobal.ts:313`) enforce `read: publishedOrLoggedIn, update: isAdminOrEditor`.
- **`Z2` (Drafts Never Leak to Public)**: `enforcePublishedReadOnGlobalBeforeOperation` (`src/globals/_shared/publishableGlobal.ts:47`) forces `args.draft = false` whenever `!req.user`, preventing unauthenticated callers from reading unpublished global drafts via `?draft=true` or Local API `overrideAccess: false`.
- **`I3` (Safe Link Schemes)**: `buttonGroup` (`src/fields/groups/button.ts:95`), `Navigation` (`src/globals/Navigation.ts:224`), and `SiteSettings` (`src/globals/SiteSettings.ts:139`, `src/globals/SiteSettings.ts:212`, `src/globals/SiteSettings.ts:275`) validate all external URLs with `validateExternalUrl` (`src/fields/link.ts:41`).
