## 1. What Changed in Round 3 (`R-49`..`R-52`)

### `R-49` [major] — Fix `querySelectorAll` iteration in `checkViewportFailSafe` (`src/components/motion/motion-controller.ts`)
- **Root cause:** In Round 2, `checkViewportFailSafe()` was changed from `doc.querySelectorAll(REVEAL_AND_COUNTUP_SELECTOR).forEach(...)` to `for (const el of Array.from(doc.querySelectorAll(REVEAL_AND_COUNTUP_SELECTOR)))` to satisfy `@typescript-eslint/no-unnecessary-condition`. In `src/p3-t14-motion.test.ts`, the fake `doc.querySelectorAll` returns `{ forEach }` without `.length` or `[Symbol.iterator]`, so `Array.from(...)` returned an empty array in the Node unit tests while working in Chromium.
- **Fix:** Updated `checkViewportFailSafe()` in `src/components/motion/motion-controller.ts` to populate `const candidates: Element[] = []` via `doc.querySelectorAll(REVEAL_AND_COUNTUP_SELECTOR).forEach((el) => { candidates.push(el) })` and iterate `for (const el of candidates)`, so both the fake DOM unit tests (`src/p3-t14-motion.test.ts`) and real browsers iterate all reveal and count-up targets cleanly.

### `R-50` [major] — Scope `CspSafeImage` `unoptimized` bypass to draft mode only (`src/components/CspSafeImage.tsx`, `src/app/(frontend)/[locale]/layout.tsx`, `src/app/(frontend)/[locale]/page.tsx`, `src/p3-t14-motion.test.ts`, `src/p3-t4-home.test.ts`)
- Added `DraftImageBypassProvider` in `src/components/CspSafeImage.tsx` (defaulting to `false`).
- Read `(await draftMode()).isEnabled` on the server in `src/app/(frontend)/[locale]/layout.tsx` and `src/app/(frontend)/[locale]/page.tsx` and passed `enabled={isDraftMode}` down via `<DraftImageBypassProvider enabled={isDraftMode}>`.
- Public renders (`draftMode().isEnabled === false`) keep Next.js image optimisation (`/_next/image` and responsive `srcset`) for all images, including `/api/media/file/...`.
- Only when draft mode is enabled on the server (`draftMode().isEnabled === true`) does `CspSafeImage` set `unoptimized` on `/api/media/file/...` URLs so authenticated editors in draft preview send their `payload-token` cookie directly.
- Added unit tests in `src/p3-t14-motion.test.ts` and `src/p3-t4-home.test.ts` covering both `draftMode = false` and `draftMode = true`.

### `R-51` [minor] — Move `ServiceCard` touch rest-state check to unit test and keep `ProjectCard` e2e on Home (`src/p3-t14-motion.test.ts`, `tests/e2e/p3-t14-motion.e2e.spec.ts`)
- Removed `/en/styleguide` navigation from the `R-43` test in `tests/e2e/p3-t14-motion.e2e.spec.ts` so the e2e test runs against Home (`/en`) on production builds (`next start`).
- Added a CSS/unit test in `src/p3-t14-motion.test.ts` verifying that `src/components/ServiceCard.module.css` and `src/components/ProjectCard.module.css` define `@media (hover: none), (pointer: coarse)` rules keeping `ServiceCard` `.description` and `.title` and `ProjectCard` `.ctaRow` and `.infoBlock` visible at rest on touch devices.

### `R-52` [minor, DoD] — Prettier formatting (`src/migrations/20261101_133828_p4_t2_r2_media_placeholder.json`)
