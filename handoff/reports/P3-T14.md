## 1. Done

### Scope 1: Tokens
- I added a `motion` group to `design/tokens.json`. It holds the durations 160, 260, 600 and
  700 ms, plus count-up 1200, hero settle 1400, sheen 400 and CTA drift 16000. It also holds the

  The generator throws if any key is missing or invalid.

### Scope 2: Primitives
- **`src/components/MotionRoot.tsx`** (client, renders nothing) is mounted once in
  `src/app/(frontend)/[locale]/layout.tsx`. It starts `src/components/motion/motion-controller.ts`.
  - `html[data-motion="on"]` is set only when `IntersectionObserver` exists and
    `prefers-reduced-motion` is not `reduce`.
  - The attribute is never set while `data-intro="active"`. Motion starts after the intro.
  - Targets already on screen when motion starts are marked final at once (`data-revealed="instant"`),
    so already-painted content is never hidden again.
  - One shared IntersectionObserver drives reveals, count-ups and the off-screen pause of loops.
  - A MutationObserver picks up content added by client-side navigation.
  - When the user switches to reduced motion at runtime, everything is revealed and motion turns
    off. Looping autoplay videos are paused under reduced motion.
- **`src/components/Reveal.tsx`** (server) renders only `data-reveal` / `data-reveal-stagger` /
  `data-reveal-step` attributes. There are four variants: `fade`, `rise` (translate only, used for
  the hero h1), `wipe` and `draw`.
- **`src/components/CountUp.tsx`** (server) always renders the final CMS text, with a visually
  hidden copy for screen readers. The parser and formatter live in `src/components/motion/motion.ts`.
  - They keep the CMS prefix and suffix, thousands grouping, decimals and Arabic-Indic digits.
  - Values that are not exactly one number stay static (e.g. `24/7`).
- **`src/styles/motion.css`**, imported from `globals.css`:
  - Every hidden "before reveal" state sits under `html[data-motion='on']` and inside
    `@media (prefers-reduced-motion: no-preference)`.
  - Reveals are CSS animations with `animation-fill-mode: backwards`, so a component's own hover
    transitions work again as soon as its reveal ends.
- **Header scroll state:** `NAVBAR_SCROLLED_THRESHOLD_PX = 24` in `src/components/Navbar.tsx`. The
  `.compact` state is transform-only (question 1 below).
- **Hover utilities:** each component gates hover with `@media (hover: hover) and (pointer: fine)`
  and shows the same state on `:focus-visible` (or `:focus-within` for tiles whose link is inside).
- CSP-safe: no inline `style` attributes; the only CSSOM write is
  `style.setProperty('min-inline-size')` for the count-up width. No new dependency.
