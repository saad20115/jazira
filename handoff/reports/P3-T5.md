### Security notes
- **Same origin:** the decoders are self-hosted from the same `three` version under
  `/systems/v022n/basis/`. No CDN.
- `meshopt_decoder` and `zstddec` are bundled and instantiate WebAssembly, so they need
  `'wasm-unsafe-eval'` (H3a). The CSP delta comes with the viewer step.
- **`public/systems/` is generated and git-ignored**, so `3d/web/` stays the single source of truth.
- **For the deployment phase** (no Dockerfile exists yet): Docker and CI must run `git lfs pull` and
  keep `3d/web/` and `3d/SHA256SUMS.txt` in the build context. Otherwise `pnpm build` now fails at the
  sync step, which is intended.
