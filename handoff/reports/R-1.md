### What Changed in Round 2

- **Unfiltered Playwright Discovery (`R1-1`, `a7b8f57`):**
  - Removed `tests/e2e/global-setup.test.ts` (`git rm`) and moved the suite to `tests/unit/e2e-global-setup.test.ts` so unfiltered `playwright test` collects only `.spec.ts` files without touching `playwright.config.ts`.
- **Live Server Database Verification (`R1-2`, `a7b8f57`):**
  - Updated `assertSafeE2ETarget` in `tests/e2e/global-setup.ts` to require `E2E_DATABASE_URL` explicitly (no fallback to `TEST_DATABASE_URL` or `DATABASE_URL`) and to require `DATABASE_URL` (when set) to equal `E2E_DATABASE_URL`, with a loopback host and a database name matching `/_(test|e2e|run_[a-z0-9_]+)$/i`.
  - Added `verifyServerUsesE2EDatabase` in `tests/e2e/global-setup.ts`, which connects to `E2E_DATABASE_URL`, writes a temporary random probe tagline into `site_settings_locales` (`en`), fetches `GET ${baseURL}/api/globals/site-settings?locale=en&depth=0` (`cache-control: no-store`), restores the row in `finally`, and refuses before `first-register` or any global mutation if the server at `baseURL` did not return that probe.
- **Single E2E Admin Email (`R1-3`, `a7b8f57`):**
  - Updated `ensureE2EAdminToken` in `tests/e2e/global-setup.ts` (and `ADMIN_EMAIL` in `tests/e2e/admin-smoke.spec.ts`) so login is only attempted against `process.env.E2E_ADMIN_EMAIL?.trim() || 'e2e-admin@aljazira.co'`. If `users` in the live-verified `_test` database contains stale rows from earlier integration tests blocking `first-register`, `resetE2ETestUsers` clears `users` in the verified `_test` database and registers `e2e-admin@aljazira.co`.
- **Recording Script Target & Database Guard (`R1-4`, `a7b8f57`):**
  - Added `assertSafeRecordingTarget` and `verifyServerUsesTestDatabase` to `scripts/record/p3-t14-motion-recordings.mjs` enforcing the same loopback + `E2E_DATABASE_URL === DATABASE_URL` + live DB probe guard before `first-register` or `site-settings` updates.
- **Secret Entropy Floor (`R1-5`, `45a1bd3`):**
  - Updated `shannonEntropyBitsPerChar` and `hasSufficientSecretEntropy` in `src/env.ts` to require at least 256 estimated bits of total Shannon entropy (`trimmed.length * shannonEntropyBitsPerChar(trimmed) >= 256`), matching the 32-random-byte baseline, and updated `src/env.test.ts` to test rejection below the 256-bit floor.
