# R-2 — Honest tests: proof harness, e2e on the production build, behaviour over source text

Audit: area B (integrity) and area E (tests), items B-02, B-05, B-06, B-14, E-02, E-04 and E-05. This
task makes the checks that were gamed **repeatable and hard to game**, so evidence scripts stop being
the only proof.

## Scope
1. **Proof harness (Step 0 of the C plan),** baseline at the last accepted commit:
   - Playwright full-page pixel diffs at zero tolerance at 7 widths × en/ar, with motion frozen;
   - accessibility-tree and normalised-DOM snapshots;
   - computed-style diffs for selected elements;
   - bundle-size and per-request query counts.

   Command: `pnpm proof:compare <baseRef>`. R-3 and R-4 use it.
2. **e2e runs on the production build** (`next build` + standalone server), with `retries: 0` in CI
   too. `next dev` is used only for a separate dev-smoke project.
3. **Turn the evidence-only checks into e2e specs:**
   - intro: play/skip decided against the browser's real `first-paint` entry (PerformanceObserver), not
     the script's own timestamp. 0 painted frames of page content before the overlay, measured with
     a paint timeline. Once per session;
   - **content is never hidden:** at every sampled frame during the intro, the main landmarks have
     `visibility: visible` and no `display: none`, with JS on, JS blocked and JS throwing;
   - CSP: 0 `securitypolicyviolation` events and 0 console errors, with their **exact texts** listed
     on failure. Nothing filtered;
   - hydration warnings = 0;
   - CLS ≤ 0.05 (all entries);
   - carousel touch drag, marquee pause on hover and focus.
4. **Replace the regex-over-source tests** (E-05 list) with behaviour tests, or delete them when the
   new e2e covers them. No test title may claim more than it checks.
5. **B-06:** remove `nextjs-portal{display:none}` from the shipped CSS. Evidence and e2e must never
   hide the dev overlay. A dev-smoke check fails on any overlay.
6. **B-14:** audits also cover the **first visit** (intro not pre-marked as seen).

## Acceptance
- **Mutation proof:** re-introduce each of the 8 historical gaming patterns in a scratch branch (for
  example `body{visibility:hidden}` while pending, an always-0 frame metric, a lowered gate, content
  `display:none` during the intro). The new suite must fail on **each one**. List them in the report.
- e2e is green on the production build with 0 retries, 3 times in a row.
