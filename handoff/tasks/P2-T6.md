# P2-T6 — `quote-requests`

Phase 2 · branch `phase-2-content` · specs: `docs/02-content-model.md` → `quote-requests` ·
security: Z1, Z4, D2, I1

## Scope
1. Collection exactly as specified (group: Sales): customer fields with validation (email,
   phone KSA/international, max lengths), `service` relationship, `locale`, `sourcePage`,
   `consent` (must be true).
2. **Revised 2026-10-23 (no Odoo):** staff workflow fields `status` (`new|contacted|quoted|closed|
   spam`, default `new`), `assignedTo` (→ users), `internalNotes` (max 3000); system fields
   read-only in admin: `emailStatus` (`pending|sent|failed`, default `pending`), `emailAttempts`,
   `emailLastError` (max 500), `ipHash`, `userAgent` (max 300). No `odoo*` fields.
3. Access: `create: () => false` (Z4); read admin + editor; update admin + editor **only on the
   workflow fields** (field-level: customer and system fields read-only for everyone); delete admin
   only.
4. Admin list: columns name, company, service, `status`, `assignedTo`, `emailStatus`, createdAt;
   filters by status, assignee and date; default sort newest first. `status` and `emailStatus` as
   coloured pills (custom cell component).
5. No raw IP field anywhere (D2). `ipHash` = SHA-256(IP + `IP_HASH_SALT`) helper in
   `src/lib/ipHash.ts` (server-only) with a unit test.

## Evidence required
- REST probes (with output): anonymous `POST /api/quote-requests` → 403; anonymous `GET` → 403;
  editor `GET` → 200; editor `PATCH` `status`/`internalNotes` → 200; editor or admin `PATCH` of a
  customer field (`email`, `message`) or a system field (`emailStatus`) → rejected or ignored (show
  which, and that the stored value is unchanged); editor `DELETE` → 403; admin `DELETE` → 200.
- `pnpm test`, `pnpm lint`, `pnpm typecheck`; migration created for this collection.

## Acceptance criteria
- [ ] Nobody can create through REST or Local API with `overrideAccess: false` (tested).
- [ ] Field-level: nobody can change customer fields or `emailStatus`/`emailAttempts`/`emailLastError` through the API (tested); staff can change the workflow fields.
- [ ] `ipHash` helper tested; no raw IP stored or logged.
- [ ] Admin list shows status pill and filters.
