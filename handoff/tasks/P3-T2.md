## Scope
Build each Figma component as a React component with **every variant and state**:
1. `Logo` — variants Full / Compact / Icon × Primary / Reversed / Dark / Navy / White; SVGs from
   `design/assets/logo/` into `public/brand/` (optimised, `viewBox` kept, no inline scripts).
2. `Button` — Gold / Dark / Glass / Outline × default / hover / focus-visible / disabled; renders
   `<a>` or `<button>`; size props.
3. `Eyebrow` — Light / Dark tone.
4. `NavLink` — Light / Dark × default / hover / active (current page via `aria-current`).
5. `Navbar` — Light / Dark theme per page (as in the Figma page frames), transparent-over-hero
   variant that turns solid on scroll, sticky, language switcher (keeps the same page in the other
   locale), mobile drawer < 1024 (focus trap, Esc, `aria-expanded`).
6. `Footer` — content from `site-settings` + `navigation`; social **icon-only** buttons with
   `aria-label`s.
7. `WhatsAppFab` — Idle / Pulse / Hover; fixed position mirrored in RTL; number from
   `site-settings.whatsapp`; pulse respects `prefers-reduced-motion`.
8. `Accordion` — collapsed / expanded, `button` + `aria-expanded` + `aria-controls`.
9. Icons — every `Icon/*` and `Icon/social/*` as typed React SVG components in
   `src/components/icons/`; the names = the `services.icon` select options; directional icons
   flip in RTL.
10. `/[locale]/styleguide` (dev only; 404 in production builds) rendering every component in every
    state, for side-by-side review.

## Evidence required (standard for all Phase 3 UI tasks)
- Playwright screenshots of the styleguide at 1440 in `en` and `ar`, saved under
  `docs/reports/phase-3/P3-T2/`, and a side-by-side image per component next to its
  `design/screenshots/components/<name>.png` sheet.
- Navbar + drawer at 1440 / 768 / 390, `ar` and `en`.
- Keyboard walkthrough notes (tab order, focus ring visible) for Navbar, drawer, Accordion.
- `pnpm test` (component tests for Navbar drawer, Accordion, language switcher), lint, typecheck.

## Acceptance criteria
- [ ] Every variant/state in the Figma sheets exists and matches (fidelity rules).
- [ ] Only tokens used; logical properties only; RTL mirror correct.
- [ ] Drawer and Accordion fully keyboard- and screen-reader-operable.
- [ ] Styleguide unreachable in production build (proof: `next build && next start` → 404).
