# P2-T1 — Shared field factories & hooks

Phase 2 · branch `phase-2-content` (from tip of `phase-1-scaffold`) · specs: `docs/02-content-model.md`
"Conventions" · security: I1, I3, I4, Z2

## Scope
Reusable building blocks every collection/global in Phase 2 uses. No collections yet.
1. `src/fields/slug.ts` — `slugField({ from: 'title' })`: unique, indexed, `beforeValidate` hook
   generating from the **English** title (fallback: transliterated Arabic), editable, validated
   `^[a-z0-9]+(?:-[a-z0-9]+)*$`, sidebar position. Arabic → Latin transliteration table in code (no
   network); unit-test 10 real titles from `design/copy/` plus Arabic ones.
2. `src/fields/link.ts` — `linkField()`: type `internal` (relationship to page globals / projects /
   services, or a fixed route select) or `external` (URL). Validation **I3**: only `http(s):`,
   `mailto:`, `tel:`; reject `javascript:`, `data:`, protocol-relative. Label localized.
3. `src/fields/videoUrl.ts` — **I4**: host allowlist `youtube.com`, `www.youtube.com`, `youtu.be`,
   `vimeo.com`, `player.vimeo.com`; parse with `URL`, never regex on the raw string; store the
   normalized URL. Helper `toEmbedUrl()` → `youtube-nocookie.com/embed/<id>` / Vimeo player URL.
4. `src/fields/order.ts` — number, default 0, admin sidebar, used for manual sorting.
5. `src/collections/_shared/publishable.ts` — the exact versions config from the content model
   (`drafts.autosave.interval 800`, `schedulePublish: true`, `maxPerDoc: 25`).
6. `src/hooks/revalidate.ts` — `afterChange` / `afterDelete` factories calling `revalidateTag`
   (tag per collection + per doc slug + per locale) and `revalidatePath` where needed; no-op
   outside the Next runtime (CLI, seed, tests); never throws into the editor's save.
7. `src/access/` — add `publishedOrLoggedIn` usage example in a test with a fake publishable
   collection (Z2).

## Evidence required
- `pnpm test` output showing the new unit tests (slug, link, videoUrl, embed, revalidate no-op).
- `pnpm lint`, `pnpm typecheck`.

## Acceptance criteria
- [ ] Slug: English source, Arabic fallback transliteration, uniqueness, pattern — tested.
- [ ] Link and videoUrl validators reject every unsafe scheme/host listed above — tested,
      including `JaVaScRiPt:` and `https://youtube.com.evil.com`.
- [ ] Revalidate hooks never break saves outside Next (tested by calling them without a Next
      request context).
- [ ] No `any`; every helper typed with Payload's `Field` / `CollectionConfig` types.
