# R-1 — Safety fixes from the 2026-10-25 audit

Audit: `docs/audit/2026-10-25-full-audit.md` §2, "Goes to: R-1". Small, security-first. No
visual change.

## Scope
1. **A-01 / C-03: escape the JSON-LD (I2).** Escape `<`, `>`, `&`, U+2028 and U+2029 in every
   `application/ld+json` payload (one shared helper). Add a test with a CMS value containing
   `</script><meta http-equiv=refresh …>` that renders inert.
2. **A-02: close the upload bypass.** Reject JSON `{url, filename}` creates on `media` and `videos`
   (no remote fetch), or apply the same magic-byte, size and video limits on that path, plus an
   allowlist and size cap. Prove it with an editor-token request that is refused.
3. **A-03 / B-15 / E-03: make test and evidence tooling safe.**
   - No passwords in git; test admins come from env or are generated per run.
   - `first-register` is called only after a guard confirms the target DB name ends in `_test` (or is a
     per-run DB) and the host is loopback.
   - The e2e setup restores every global it changes (`arabicEnabled` back to its original value).
4. **A-05 / D-05:** `projects.reviewNote` read and update for the admin role only, with a field-access
   test (if P4-T2 has not already done it).
5. **A-06:** explicit `jobs.access` (admin only, or the job runner's secret), and remove
   `payload-jobs` from the Z1 test's skip list.
6. **D-14 / E-09: reseed guard.** `--reseed` needs an explicit `--i-understand-this-deletes-content`
   flag **and** a DB-name allowlist; it fails closed when `NODE_ENV` is unset. Media is never deleted
   unless it is seed-owned.
7. **E-07: test DB isolation.**
   - Every suite asserts that the DB name ends in `_test` before it migrates or truncates; no fallback
     to `DATABASE_URL`.
   - The suites are order-independent: run them in random order twice.
8. **A-08:** secret validation measures entropy (≥ 32 random bytes encoded), not length, and rejects
   a superuser in `DATABASE_URL`. **A-09:** SMTP fails loudly in production when it is unset, with no
   silent `127.0.0.1:1025` fallback. **A-10:** `/api/*/file/*` responses get
   `Content-Security-Policy: default-src 'none'; sandbox` and `X-Content-Type-Options: nosniff`.

## Acceptance
- Each item has a test that fails on the snapshot `0c4005b` behaviour and passes after the fix.
- No public page changes visually (the R-2 harness can come later; here, the full-page pixel diff for
  `/en` and `/ar` is 0).
