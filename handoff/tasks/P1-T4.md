# P1-T4 — Migration, e2e smoke, CI, phase report & PR

Phase 1 · specs: `docs/04-phases.md` Phase 1 items 1 (repo/PR), 9 (e2e), 10, 11 ·
security: S3 (gitleaks), B1, B3, B4

Start only after P1-T3 is `ACCEPTED`.

## Scope
1. **Initial migration** — `pnpm payload migrate:create initial`, committed. Prove on an empty DB:
   `migrate` → `migrate:status` → `migrate:down` → `migrate` all succeed.
2. **Playwright smoke** (`pnpm test:e2e`) — admin login page renders in Arabic
   (`<html lang="ar" dir="rtl">`, Arabic labels visible) and in English after switching
   (`lang="en"`, `dir="ltr"`). Use the preinstalled browser where available.
3. **CI** `.github/workflows/ci.yml` (B4):
   - every third-party action pinned by **full commit SHA** (with a version comment);
     `permissions: contents: read` at the top.
   - Node 24, pnpm 10.34.7, Postgres 18 service (same digest as dev compose).
   - Steps: `pnpm install --frozen-lockfile` → lint → typecheck → format:check → migrate →
     test → build → test:e2e → `pnpm audit --prod --audit-level high` → gitleaks.
   - Secrets for CI are generated per run (e.g. `openssl rand`), never committed.
4. **Dependabot** (B3): weekly npm + GitHub Actions; group all `@payloadcms/*` (and `payload`)
   into one update.
5. **GitHub**: if the user has created the private repo, push `main` and `phase-1-scaffold`,
   open the PR `Phase 1 — Scaffold & foundations`, protect `main` (PR required, CI required).
   If there is no remote yet, say so in the report and leave the commits on the branch.
6. **Phase report** — `docs/reports/phase-1.md` in the exact format from `AGENTS.md`, covering the
   whole phase (all four tasks), with full outputs of: `pnpm ls --depth 0`, lint, typecheck,
   test, build, audit, `git log --oneline main..HEAD`. Same text as the PR description.

## Evidence required in the report
- Migration up/status/down/up output on an empty DB
- `pnpm test:e2e` output + screenshots (ar + en) in `docs/reports/phase-1/`
- `pnpm build` output (route table) and `pnpm audit --prod` output
- Local gitleaks run output (`gitleaks git` over the branch)
- CI run link and status (or "no remote yet")

## Acceptance criteria
- [ ] Initial migration committed; up/down/up works on a clean DB.
- [ ] e2e smoke passes in ar and en.
- [ ] CI workflow: actions pinned by SHA, least permissions, all listed steps present.
- [ ] `pnpm audit --prod`: zero high/critical (anything lower explained).
- [ ] gitleaks: no findings.
- [ ] `docs/reports/phase-1.md` complete; every Phase 1 acceptance criterion from
      `docs/04-phases.md` marked with proof.
- [ ] CI green on the PR (or explicitly pending a remote).
