## Scope
1. `ServiceTile` (Default / Featured), `ServiceCard` (Default / Hover), `ProjectCard`
   (Completed / In progress × Default / Hover; status label from i18n), `PartnerTile`,
   `BrandTile` (logo or wordmark fallback).
2. `TeamCard` — Default / Hover + entrance sequence (Enter 1→5 frames) on first view via
   IntersectionObserver; `Portrait` placeholder when no photo; `Avatar` initials fallback.
3. `TeamMember` (staff marquee item), `TeamMarquee`, `LogoMarquee` — infinite CSS-transform
   marquees: pause on hover/focus, duplicated items `aria-hidden`, reversed in RTL, static row
   with `prefers-reduced-motion`.
4. `ServicesCarousel` — Positions 1→5 as in the sheet: auto-advance, drag/swipe, prev/next buttons,
   pause on hover/focus, `aria-roledescription="carousel"`, slide labels, reduced-motion = no
   auto-advance. No carousel library unless justified in the report (prefer none).
5. All components take CMS types from `payload-types.ts` (no ad-hoc prop shapes) and use
   `next/image` with correct `sizes`.
6. Add them all to the styleguide with mock data clearly marked as mock.

## Evidence required
Standard Phase 3 evidence (see P3-T2) for every component, plus a short screen recording (GIF/MP4)
of marquee, carousel and team-card entrance in `en` and `ar`.

## Acceptance criteria
- [ ] Every state/variant matches its sheet (fidelity rules).
- [ ] Animations use `transform`/`opacity` only, honour `prefers-reduced-motion`, pause when
      off-screen.
- [ ] Carousel operable by keyboard and touch; marquees pause on hover/focus.
- [ ] No layout shift when images load (fixed aspect ratios).
