# P3-T1 — Frontend foundations: tokens, fonts, i18n routing, CSP, data layer

Phase 3 · branch `phase-3-frontend` · specs: `docs/01-architecture.md` §3, `docs/05-design.md`
(incl. "CTO decisions") · security: H3, I2, Z6

## Scope
1. **Tokens** — generate `src/styles/tokens.css` from `design/tokens.json`: colours
   (`--gold-500 … --navy-950`, text, border, surface, white), text styles as utility classes
   (`.t-display-xl`, `.t-h2`, `.t-body-m`, `.t-label-eyebrow`, …) with the exact family, weight,
   size, line-height, letter-spacing; plus the mobile/tablet scale from "CTO decisions" §1.
   A script `pnpm tokens` regenerates it; CI fails if `tokens.css` is stale.
2. **Styling approach** — CSS Modules + the tokens (no Tailwind, no CSS-in-JS runtime). Logical
   properties only. Breakpoints as custom media in one file.
3. **Fonts** — `next/font/google`: Poppins (weights used in tokens) and Noto Kufi Arabic (same
   weights), self-hosted at build, `display: swap`, subset `latin` / `arabic`. `ar` pages use Kufi
   for all text, `en` pages Poppins. Arabic letter-spacing 0, line-height +10% (§2).
4. **i18n routing** — `src/app/(frontend)/[locale]/…` with `ar` (default) and `en`; `/` → 308 to
   `/ar`; unknown locale → 404. `<html lang dir>` per locale. Dictionaries
   `src/i18n/{ar,en}.ts` for UI strings, typed so a missing key is a type error.
5. **`proxy.ts` + CSP (H3)** — per-request nonce; public CSP exactly as in H3 (frames only the I4
   hosts); `/admin` gets its own relaxed policy, every relaxation commented and listed in the
   report. Zero CSP violations in the console.
6. **Data layer** — **through the typed Z6 wrapper from the P2-T8 review R-6** (`cmsFind`/`cmsFindByID`/
   `cmsFindGlobal`/`cmsCount`, `overrideAccess: false` set inside, not passable; no `payload` import
   allowed in `src/app/(frontend)` or `src/components`) — `src/lib/cms/*.ts` server-only functions using the Payload Local API with
   `overrideAccess: false` (Z6), `draft` only when Next draft mode is on, `locale` + `fallbackLocale`,
   wrapped with `unstable_cache`/tags matching the revalidate hooks from P2-T1. Typed returns
   from `payload-types.ts`.
7. **Draft mode / Live Preview route** — `/api/preview` (secret-checked, logged-in editors only)
   enabling Next draft mode and redirecting to the doc's URL; exit route.
8. Base layout per locale: skip-link, `<main>`, metadata defaults from `site-settings`.
9. **Client-bundle guard (from the P2-T6 review):** extend `scripts/check-client-bundle-sentinels.mjs`
   so `pnpm build` also fails when server-only libraries reach `.next/static` (e.g. markers from
   `payload` server code, `drizzle-orm`, `pg`, `nodemailer`, `sharp`) — prove it with a throwaway
   client component importing `@/security/apiError` (must fail) vs `@/lib/quote/schema` (must pass).

## Evidence required
- `curl -sI http://localhost:3000/` (308 → `/ar`), `/ar` and `/en` headers incl. CSP with nonce.
- Browser console of `/ar` and `/en`: zero CSP errors, zero hydration warnings (screenshot).
- Screenshot of a temporary type specimen page (`/[locale]/_specimen`, dev only, 404 in prod)
  showing every text style in ar and en next to `design/screenshots/components/` sheets.
- `pnpm test`, `pnpm lint`, `pnpm typecheck`, `pnpm build`.

## Acceptance criteria
- [ ] Tokens generated, not hand-copied; no raw hex in components (`grep` proof).
- [ ] `/` → `/ar`; `lang`/`dir` correct; fonts self-hosted (no request to Google at runtime —
      network log proof).
- [ ] CSP with nonce on public pages, documented admin relaxation, zero violations.
- [ ] All public data access via Local API with `overrideAccess: false`; drafts only in draft mode.
