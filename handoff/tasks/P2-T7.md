# P2-T7 — Dashboard UX: Arabic admin, Live Preview, dashboard home, branding

Phase 2 · branch `phase-2-content` · specs: `docs/01-architecture.md` §3 (Live Preview, admin
i18n) · security: Z1, H3 (admin policy comes in P3-T1)

**Moved 2026-10-23:** this task now runs on `phase-3-frontend` right after P3-T4, so Live Preview
points at real pages (no placeholder page needed).

The client's staff are non-technical. The dashboard must be self-explanatory in Arabic.

## Scope
1. **Arabic first**: every collection/global/field has Arabic + English labels and, where useful, a
   one-line `admin.description`; select options labelled in both languages; validation messages
   localized (custom ones too).
2. **Navigation groups** in this order: المحتوى (Content), الصفحات (Pages), الشركة (Company),
   الوسائط (Media), المبيعات (Sales), الإعدادات (Settings), النظام (System).
3. **Live Preview** for `projects`, `services` and every page global: breakpoints 1440 / 768 / 390,
   preview URL per locale, using the `/api/preview` route planned in P3-T1 (implement the route
   now with a placeholder page if P3 is not there yet, and say so).
4. **Dashboard home** (custom `afterDashboard` / dashboard view): cards for quote requests by
   status (new / contacted / quoted, last 7 days, plus any `emailStatus: failed`), drafts awaiting publish, scheduled publishes,
   last 5 edited items, quick links ("Add project", "Edit home page", "Site settings"). Data via
   Local API with the viewer's access (editors see only what they may).
5. **Branding**: admin logo + icon from `design/assets/logo/`, brand colours on the admin
   accent via CSS variables in `custom.scss` (no Payload internals patched), favicon, admin
   `meta.titleSuffix`.
5b. Quote requests: show `phone` through `formatPhoneForDisplay` in the list and edit view (stored
   value stays E.164); extend it to common non-KSA formats or show E.164 as is (P2-T6 review).
6. **Arabic RTL check** of the whole admin: list views, edit views, rich text, upload, relationship
   pickers, dashboard home.

## Evidence required
- Screenshots (Arabic + English) of: dashboard home, nav groups, a project edit view with Live
  Preview open at 390, `home-page` with Live Preview, quote list.
- Editor-role screenshot of dashboard home (no users/settings admin cards).

## Acceptance criteria
- [ ] No English-only label left in the Arabic admin (screenshot walk-through of every
      collection/global).
- [ ] Live Preview updates while typing for a project and the home page.
- [ ] Dashboard home cards respect access (editor vs admin).
