## Scope
1. **Config-enumeration test** (Z1): loads the Payload config, iterates every collection and
   global, fails if any of `read/create/update/delete` (globals: `read/update`) is missing or is
   the default.
2. **Role matrix integration tests** (Z5) against REST with real sessions: anonymous / editor /
   admin × every collection and global × read/create/update/delete, including the specific cases
   in Z5. Generate the matrix as a table in the report from the test results.
3. Z6 check: a lint rule or test that fails if `payload.find/findByID/findGlobal` is called in
   `src/app/(frontend)` or `src/lib/cms` without `overrideAccess: false` (or a comment explaining
   why).
4. Migrations: `migrate:fresh` on an empty DB, `migrate:down` all the way, `migrate` again — clean.
5. Phase-2 report (`docs/reports/phase-2.md`, AGENTS.md format) incl. the editor flow evidence
   from `docs/04-phases.md` (create project in Arabic, add English, save draft, preview live,
   publish — screenshots or recording).
