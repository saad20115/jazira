# P7-T1 — Arabic editor guide for the dashboard

Phase 7 · branch `phase-7-handover`

## Scope
`docs/guide/editor-guide-ar.md` (Arabic, plain language for non-technical staff) + screenshots
from the real admin (`docs/guide/img/`), built against the seeded data from Phase 4:
1. Logging in, changing password, forgot password; what the editor vs admin role can do.
2. Switching the admin language; editing Arabic then English (fallback explained).
3. Projects: create, cover image + gallery (good image sizes, focal point, alt text — why it
   matters), video upload vs YouTube/Vimeo link, featured on Home, draft → preview → publish →
   schedule, restoring an older version.
4. Services, team (leadership vs staff, photo, hide a member), brands & marquee, clients,
   materials table.
5. Home page sections: enabling/disabling, order, stats, CTA; other page globals; site settings
   (phone, WhatsApp, email, socials, address, map image).
6. Media library: allowed formats and sizes, replacing an image, what happens to pages.
7. Quote requests: reading them, statuses (pending / sent / failed), what "retry" does (admin).
8. What is **not** editable from the dashboard (icons, logo files, 3D model) and whom to ask.

## Acceptance criteria
- [ ] Every screenshot taken from the current build in Arabic admin UI.
- [ ] Each task in the guide was performed once while writing it (no untested steps).
- [ ] Reviewed against the actual role permissions (editor cannot see what the guide says they
      cannot).
