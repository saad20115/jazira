# R-4 — Back-end and tooling refactor

Audit: area D ("Refactor plan", 12 steps; the slug simplification goes last) and area E ("Refactor
themes", 6). No schema change unless a migration is planned and reviewed.

## Scope
- **D:**
  - D-04: sort materials by `itemNo`, with a test that checks order, not just that it is an array;
  - D-06: slug locking must not depend on process memory; split `slug.ts` (1,012 lines);
  - D-07: the Team hook uses the public Payload API, not adapter internals, and never swallows errors;
  - D-08: the validator runs inside the request transaction;
  - D-12: the project list uses `select` + depth 1;
  - D-13: the CMS client must not map DB errors to "not found";
  - D-15..D-17: dead code, unused cache tags, the stale doc line.
- **E:**
  - E-01: CI is green on a clean runner (install Playwright browsers; a first run on a fork or a
    local `act`);
  - split the monolithic per-task test files into per-unit files (same assertions, same count, listed
    1:1);
  - the custom ESLint rules get their own tests proving they fire;
  - script hygiene (no process killing by name or port, no writes outside the repo, no hard-coded
    paths);
  - E-06, E-08, E-11..E-18 as listed.

## Acceptance
- Test count before and after is listed per suite; no assertion is lost in the split (a mapping
  table).
- CI run log from a clean runner attached.

## Rules for every R-task
- **Source:** `docs/audit/2026-10-25-full-audit.md`, plus the area report linked for each item.
  Re-read the cited `path:line` on the current branch first: code moves, so confirm each finding is
  still present, and report any that is already gone.
- **Isolation:** your own git worktree and branch, your own Docker project and ports (the CTO assigns
  them), and only the files this card names. Stop and ask for anything else.
- **Order:** this card starts only after the in-flight P3-T13 and P4-T2 are accepted and merged.
- **Proof:** for every item, show a failing test or reproduction **before** the fix, and the same test
  passing after. A fix without a test that can fail is not done.
- **The DoD comes from a new clone** (`git lfs pull`), with `format:check`. Every run is reported. No
  retries, no filtered logs, nothing hidden.
- **Report** in `handoff/reports/<ID>.md` (AGENTS.md format), with a table: finding → commit → test.
