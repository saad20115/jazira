# P5-T2 — Email notification job, staff workflow, CSV export, retention

Phase 5 · branch `phase-5-quotes` · specs: `docs/01-architecture.md` §5, `docs/02-content-model.md`
`quote-requests` · security: Q1–Q4, S1, S4, D2, D3

**Rewritten 2026-10-23:** the owner removed the Odoo integration. Quote requests live in the
dashboard and are announced to the sales inbox by email. Nothing in this task talks to Odoo.

## Scope
1. Payload **Jobs** task `notifySalesOfQuote` (same runner as scheduled publish, P2-T4 R-1):
   sends the P5-T1 template to `SALES_INBOX` only (Q1 — never to the visitor's address).
   Retries with exponential backoff (e.g. 5 attempts over ~1 h); updates `emailStatus`,
   `emailAttempts`, `emailLastError` (sanitized, max 500, no credentials — Q2). (P2-T6 only truncates — the scrubbing of SMTP credentials/hosts/addresses happens here, with a test.) **Idempotent:** if
   `emailStatus` is `sent`, never send again, even if the job runs twice.
2. Admin action "Resend notification" on a request with `emailStatus: failed` (admin only):
   re-enqueues the job; tested not to double-send.
3. **Staff workflow** in the edit view: `status` (`new → contacted → quoted → closed`, or `spam`),
   `assignedTo`, `internalNotes`; customer fields shown read-only. List view filters by status and
   assignee (from P2-T6) and a "Mine" quick filter for the logged-in user.
4. **CSV export** (admin only): button on the list view exporting the current filter (UTF-8 with
   BOM so Excel shows Arabic), columns = customer fields + status + assignee + createdAt (no
   `ipHash`, no `userAgent`, no `internalNotes`). Formula-safe (Q3: prefix `'` for cells starting
   with `=`, `+`, `-`, `@`, tab or CR). Each export is logged (user ID, time, row count; no PII).
5. Retention job (D3): daily, deletes quote requests older than 24 months; first run in dry-run
   mode that only logs the count.
6. CI step: grep `.next/static` for `PAYLOAD_SECRET`, `IP_HASH_SALT`, `SMTP_`, `SALES_INBOX` —
   must find nothing.
7. Phase-5 report `docs/reports/phase-5.md`.

## Evidence required
- Tests:
  - email sent exactly once;
  - SMTP down → retries, then `failed`, and the request is still stored;
  - resend after failure sends once;
  - the job running twice does not double-send;
  - no email goes to the visitor's address;
  - an editor cannot export and cannot resend;
  - the CSV escapes `=SUM(A1)`, `+1`, `-1`, `@x`;
  - retention deletes only items older than 24 months.
- Mailpit screenshots (ar + en) and admin screenshots: the list with status and email pills, the
  edit view with the workflow, the export button, a CSV opened in Excel showing correct Arabic.
- CI grep output. Evidence rules as in `handoff/README.md` §Evidence files (incl. `citations.log`).
