# P5-T2 — Odoo client, Jobs queue, retries, idempotency, admin retry, retention

Phase 5 · branch `phase-5-quotes` · specs: `docs/01-architecture.md` §5 · security: O1–O4, S1,
S4, D3

## Scope
1. `src/lib/odoo/` (server-only): interface `createLead(input): Promise<{ id: number }>` with two
   adapters — **JSON-2** (`POST /json/2/crm.lead/create`, `Authorization: bearer <key>`) for Odoo
   19+, and **JSON-RPC** (`/jsonrpc`, `object.execute_kw`) for ≤ 18 — chosen by `ODOO_PROTOCOL`.
   HTTPS only in production, 10 s timeout, no customer string ever used in a domain/filter (O4).
2. Field mapping (document it in `docs/odoo-mapping.md`): name, email, phone, company → `partner_name`,
   service + message → `description`, locale, source page, a `website_quote_id` reference in the
   description for traceability. Test it against the mock.
3. **Mock Odoo server** for tests (both protocols): success, timeout, 500, malformed JSON, auth
   error.
4. Payload **Jobs** task `pushQuoteToOdoo`: retries with exponential backoff (e.g. 5 attempts over
   ~1 h), updates `odooStatus`, `odooAttempts`, `odooLeadId`, `odooLastError` (sanitized: strip
   credentials/URLs with keys, max 500 chars — O3). **Idempotent**: if `odooLeadId` is set, never
   create again (O2). Jobs runner configured for dev and documented for production (autorun or a
   cron route protected by a secret).
5. Admin: "Retry push" action on a failed quote (admin only), re-enqueues the job.
6. Retention job (D3): delete quote requests older than 24 months, daily; dry-run log first.
7. CI step: grep `.next/static` for `ODOO_`, `PAYLOAD_SECRET`, `IP_HASH_SALT`, `SMTP_` — must find
   nothing.

## Evidence required
- Tests: success; Odoo down → retries then `failed`; invalid response → `failed` with sanitized
  error; retry after failure does not duplicate the lead; idempotency when the job runs twice;
  retention deletes only > 24 months.
- Screenshot of the admin list with pending / sent / failed and the retry action.
- CI grep output. Phase-5 report (`docs/reports/phase-5.md`) — P5-T3 marked as hard stop.
