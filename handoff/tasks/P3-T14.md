# P3-T14 — Motion & interaction pass (site-wide primitives + Home)

Phase 3 · branch `phase-3-frontend` · owner 2026-10-25: "the site is almost dead: no animation, no
hover interaction, no fitting motion per section" · spec: `docs/05-design.md` §20 (Motion system),
§10 (states). **Order:** after P3-T13 and the P4-T2 submission, and **before P3-T6**. The inner pages
reuse these primitives.

## Scope
1. **Tokens:** add the §20 motion tokens to `design/tokens.json` and regenerate `tokens.css`
   (`tokens:check` covers them).
2. **Primitives:**
   - `MotionRoot`: sets `html[data-motion="on"]` when `IntersectionObserver` exists and reduced
     motion is off, after the intro.
   - `Reveal` / `data-reveal` and `data-reveal-stagger`: one shared observer, fires once.
   - `CountUp`: parses the number from the CMS text and keeps its suffix.
   - Header scroll state.
   - Hover utilities.
   - All CSP-safe, server components wherever possible, no new dependency.
3. **Apply catalogue items 1–13 to the Home page and the shell** (header, footer, buttons, links,
   cards, marquee tiles, carousel, accordion, stats, CTA).
4. **Styleguide:** a "Motion" section that demos each primitive, with a reduced-motion toggle note.
5. **Tests:**
   - unit tests for `CountUp` parsing and for `MotionRoot` gating (no IO / reduced motion → never
     hidden);
   - an e2e test that **with JS disabled and with the main chunk blocked, every section is visible**;
   - an e2e test that under reduced motion nothing animates.

## Acceptance
- **Recordings (webm):** a full Home scroll at 1440 and 390 (en), plus one in `ar` with the switch
  on. Hover recordings of buttons, service cards, project cards and brand tiles. A reduced-motion
  recording shows static content.
- **Eye check first** (CTO rule): it must feel alive but calm. The CTO and the owner judge the
  recordings.
- **No regressions:**
  - CLS ≤ 0.05 (throttled 412, all entries);
  - Lighthouse mobile Performance no more than 3 points below the P3-T4 r5 baseline (single
    attempt, every run reported);
  - LCP not later than the baseline; the hero h1 is never `opacity:0`;
  - console and CSP clean;
  - INP < 200 ms on the hover-heavy sections (web-vitals in Playwright).
- **No content depends on JS** (no-JS and blocked-chunk e2e).
- Full DoD from a **new** clone; `format:check` included.
