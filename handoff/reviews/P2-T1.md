# P2-T1 review

## Round 1 — 2026-10-22 — CHANGES_REQUESTED
The security validators are excellent: every link/video bypass I tried was rejected (details in
Verified). Three major issues: field overrides break the factories, slugs come out Arabic in the
real admin flow, and draft autosave purges the public cache every 800 ms.

### Findings
- R-1 [major] `src/fields/slug.ts:301`, `src/fields/videoUrl.ts:228`, `src/fields/order.ts:33` —
  the final `...overrides` spread replaces the merged `hooks`/`admin`.
  `slugField({ overrides: { hooks: { afterRead: [] }, admin: { readOnly: false } } })` →
  `beforeValidate` hooks **0**, admin `{"readOnly":false}` (auto-generation, sidebar and
  description gone); same for `videoUrlField` (normalize hook lost) and `orderField` (sidebar
  lost). Fixed = deep-merge `admin` and **concatenate** hook arrays (factory hooks first); tests
  for each factory proving defaults survive overrides.
- R-2 [major] **Slug source in the real admin flow (CTO rule below).** With `defaultLocale: 'ar'`
  Payload passes `title` as the current locale's string, so an editor creating in Arabic gets
  `فندق سوفيتيل` → `fndq-swfytyl`, and adding the English title later keeps it. Your tests only
  use `{en, ar}` objects, which the admin never sends. **Rule:**
  1. A hidden checkbox `slugLocked` (default false) per document.
  2. While `slugLocked` is false, the slug is (re)generated on every save: from the **English**
     title if one exists (read it via `req.payload.findByID({ locale: 'en' })` when saving in
     `ar`, or from the incoming data when saving in `en`), otherwise transliterated Arabic.
  3. `slugLocked` becomes true when the editor types a slug manually **or** the document is
     first published (published URLs never change silently).
  4. Integration tests with the real per-locale flow: create in `ar` → transliterated; add `en`
     title → English slug; publish; change English title → slug unchanged.
- R-3 [major] `src/hooks/revalidate.ts:141-159` — no `_status` check: a draft autosave
  (`draft` → `draft`) fires 12 revalidations (6 tags + 6 paths incl. `/ar`, `/en`); with 800 ms
  autosave, editing a draft keeps purging the public cache. Fixed = revalidate only when the doc
  is published now or was published before (unpublish), plus deletes; drafts are seen through
  draft mode, not the cache. Test it.
- R-4 [minor] `src/hooks/revalidate.ts:24` swallows **any** `Invariant:` error silently. Match only
  the outside-runtime case ("static generation store missing"); log everything else.
- R-5 [minor] `src/hooks/revalidate.test.ts` never mocks `next/cache`, so tag/path lists and the
  `disableRevalidate` skip are untested. Mock it and assert the exact calls.
- R-6 [minor] `slug.ts:214-215` — a manual slug is not normalised (`'My Custom Slug'` is kept and
  then rejected). Your report says manual slugs are normalised via `slugify`; the code does not.
  Normalise manual input, and correct the report.
- R-7 [minor] `slug.ts:214` — a manual slug skips the uniqueness check and fails later with a DB
  unique-constraint error. Return a friendly localized validation message instead.
- R-8 [minor] no length cap: a long title gives a 999-char slug. Cap at 80 chars, cut at a
  word boundary.
- R-9 [minor] `slug.ts:245-256` uniqueness uses `like` + `limit: 100`; >100 contains-matches can
  collide. Query exactly `base` and `base-<n>` and take the max suffix.
- R-10 [minor] `src/fields/videoUrl.ts:131-157` — Vimeo unlisted links lose `h=<hash>` (embed will
  fail) and `vimeo.com/<id>/<hash>` is rejected; `youtu.be/…?t=10` loses the start time;
  `m.youtube.com` is rejected. Keep `h` and `t`/`start`, accept those two formats, keep all the
  injection guards.
- R-11 [minor] `src/fields/link.ts:104-155` — internal paths: reject `\` and percent-encoded `/`
  (`/a\b`, `/%2F%2Fevil.com`); validate `internalPath` only when `internalRoute === 'custom'`;
  define precedence when both a `reference` and a route are set (reference wins) and test it.
- Not a finding: symbol/emoji-only titles produce no slug and the editor must type one — fine.

  hook would generate now, or (better) only when the `slug` field was actually changed by the
  user (`req.data` vs `originalDoc`) — test the stale-payload sequence.
- R-15 [minor] suffix resolution near the 80-char cap: when the base is shortened to make room for
  `-N`, collisions with the shortened base are not queried (`slug.ts:451`). Query using the final
