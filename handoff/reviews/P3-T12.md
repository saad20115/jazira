### Findings
- **R-1 [major] Arabic leaks through metadata while the switch is off.**
  - `generateMetadata` (`[locale]/layout.tsx:121`, `page.tsx:271`) is not gated. Anonymous 307
    bodies for `/ar/*` carry about 150–170 Arabic words (`<title>`, description, `og:*`,
    `twitter:*`), and so does `/ar?_rsc`.
  - **Fix:** when `ar` is off and there is no staff preview, return `en` metadata or none. Add a test
    that the 307 body and the RSC payload contain no Arabic.
- **R-2 [minor, DoD] `format:check` fails on 4 files** from this commit (the evidence script,
  `migrations/index.ts`, the migration JSON and the unit test). The report left `format:check` out.
  It belongs in every DoD.
- **R-3 [major] The e2e tests are missing, and the existing e2e fails in the default state.**
  - Scope §6 requires e2e; there is none for P3-T12.
  - `tests/e2e/p3-t2.e2e.spec.ts:8` (`/ar/styleguide`) fails on a fresh DB, because the switch is off.
  - **Fix:** a Playwright global setup that turns `arabicEnabled` **on** for the existing ar suites.
    Add new specs for: off → 307 with no switcher and no Arabic in the body; on → 200 RTL with the
    switcher; and the toggle. Commit an e2e run log.
- **R-4 [minor] Leftover `'ar'` defaults:**
  - `QuoteRequests.ts:150-151`: `locale ?? 'ar'`, `fallbackLocale: 'ar'`;
  - `QuoteRequests.ts:299`: anything other than `en` becomes `ar`;
  - `QuoteRequests.ts:488`: `defaultValue: 'ar'`;
  - `fields/richText.ts:534`;
  - `globals/HomePage.ts:184`.

  Use `DEFAULT_LOCALE`, or add a one-line justification for each.
- **R-5 [CTO decision] `/` → `/en` is now a 307 (temporary), not a 308.** Browsers cached the old
  `/` → `/ar` 308 for good, and the default may change again. This applies to every locale-default
  redirect.
- **R-6 [nit]** `client.ts:327-331`: parse `URLSearchParams` (`preview=true` must be an exact
  param), and require the referer to be same-origin `/admin`. Not exploitable today, because staff
  auth gates it.
- **Info, accepted:**
  - The flag cache is per process. That is fine with one container; note it for P6.
  - `/api/...?locale=ar` serves Arabic, which is expected for API consumers.

**Order:** P3-T4 r4 (in progress) → P3-T12 r2 (small) → P4-T2.
