### Findings
- **R-42 [major] No fail-safe reveal.** Once `html[data-motion='on']` is set, a target is revealed only
  by the shared observer at 15 % (`src/styles/motion.css:73-98`, the controller in
  `motion-controller.ts`). If the controller throws, or a target never reaches the threshold, the content
  stays at opacity 0. Only `beforeprint` and a reduced-motion switch call `revealAll`.
  **Fixed looks like:**
  - any exception in the controller removes `data-motion` (everything visible);
  - a target that is in the viewport for 1 s without being revealed is revealed;
  - e2e at 1440 and 390 for: an anchor jump (`/en#cta`), a fast scroll to the bottom, a reload
    mid-page, and a load in a background tab. No target may be left at opacity 0 or clipped.
- **R-43 [major] Content unreachable on touch devices.** Hover is now gated on
  `(hover:hover) and (pointer:fine)`. These rest states start at opacity 0 and can no longer be shown
  by a tap:
  - `ServiceCard.module.css:154` (`.description`, real content; P3-T6 reuses ServiceCard);
  - `ProjectCard.module.css:185` (`.ctaRow`, "View project").

  **Fixed looks like:** on `(hover:none)` they are visible at rest. Add an e2e at 390 with
  `hasTouch` that checks both.
- **R-44 [major] Hero entrance never plays on a first load** (report Q2). §20.3 requires the eyebrow,
  subtitle and CTAs to rise in with a stagger. **Fixed looks like:**
  - a CSS animation from first paint (fill-mode `backwards`), not hiding painted content later;
  - while `html[data-intro='active']` it is paused, and it plays when the intro ends;
  - it runs once per page view, ≤ 900 ms in total, and always ends visible (also with JS off);
  - it is off under `prefers-reduced-motion`. The h1 only translates, never opacity 0.
- **R-45 [minor] The hero background settle is spent behind the intro.** `page.module.css:799-803`
  runs on every load, so on a first visit it plays under the intro. Give it the same intro pause as
  R-44.
- **R-46 [minor] The accordion unit test no longer proves the panel is hidden.**
  `src/p3-t2-components.test.ts:418-441` now asserts `inert` only. Also assert the collapsed class
  (`panelGrid` without `panelGridExpanded`), and run `tests/e2e/p3-t2.e2e.spec.ts` in your fresh
  clone (it was skipped).
- **R-47 [minor] Glass and Outline buttons get no hover shadow** (`Button.module.css:194-220`). §20.4
  says "lifts 2 px with a shadow" for every variant.
- **R-48 [minor] ServiceTile focus.** `ServiceTile.module.css` uses `:focus-within`, so a mouse click
  shows the focus style; use `:focus-visible` on the link. The new `overflow:hidden` (`:15`) must not
  clip the focus ring: show it in a screenshot.
