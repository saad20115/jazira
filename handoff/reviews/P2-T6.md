### Findings
- **R-1 [major, R-12 rule] The report describes code that does not exist.**
  - The report says `ipHash.ts` "imports `'server-only'`". It doesn't: the protection is a
    runtime `typeof window` guard. That is a valid choice, since `server-only` breaks the Payload
    CLI as `env.ts` documents, but describe it as it is and list it under Deviations.
  - The report says ipHash is "protected by ESLint `no-restricted-imports`". No such rule
    exists; the real protection is the custom `local/no-server-in-client` rule.
  - `commit.log` holds only the hash. The rule also asks for `git status --porcelain`.
- **R-2 [major, phase-wide] Staff can rewrite `createdAt`.**
  - An editor's `PATCH {"createdAt":"2000-01-01…"}` → 200, and the value is stored. The default
    sort, the date filter and the future 24-month retention (D3) all use `createdAt`. Staff could
    therefore hide a request from retention or get it deleted early.
  - The same happens in `projects`, so it applies to every collection.
  - **Fix:** one shared mechanism that makes `createdAt` immutable through the API (field access
    `update: () => false` via a shared helper, or a hook that drops it), applied to **all**
    collections.
  - **Tests:** a test per collection, and one generic test that walks the config.
- **R-3 [minor] The phone validator does not cover `00966` as its comment says.**
  - Only `+966` gets the national-length check, so `00966…` passes on digit count alone.
    `+111111111111111` and `966573534185` (no `+`) are also accepted.
  - **Fix:** normalise `00` to `+` first, and require `+` for any international number.
  - Test the cases above plus the good ones that already pass.
- **R-4 [minor, CTO decision] Keep quote history readable when a service is deleted.**
  - Deleting a service sets the quote's `service` to null.
  - **Fix:** add a read-only system field `serviceTitle` (snapshot of the service title in the
    request's locale, set by the handler in P5). Keep the relation as `set null`.
  - `assignedTo` → `set null` is fine.
- **R-5 [minor/UX] The assignee shows as "بدون عنوان" (Untitled) in the edit view.**
  - **Fix:** set `Users.admin.useAsTitle`, using a display name if one exists, otherwise `email`.
- **Note (Phase 5):**
  - `emailLastError` is only truncated. Credential scrubbing (Q2) belongs in the P5-T2 email
    job; note it there.
  - The phone rules (R-3) must use the same zod schema as the P3-T9 form.
