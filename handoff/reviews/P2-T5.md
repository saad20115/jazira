### Findings
- **R-1 [major, security I3] Link URLs are not validated on draft saves.**

    → 200, stored. `data:text/html,…` and the internal path `//evil.com` are stored the same way.
  - Publish rejects them, but drafts are exactly what Live Preview and admins render, so this is a
    stored-XSS vector against staff.
  - **Fix:** run the `linkField` validation in a hook that also runs on drafts and autosave, as you
    did for IDs in P2-T4 R-6. Apply it to every use of `linkField`, in collections and globals.
  - **Tests:** `javascript:`, `data:`, `vbscript:`, mixed-case and whitespace-prefixed schemes,
    and `//host` internal paths → 400 on draft and publish.
- **R-2 [major, spec] `interactiveSystems.systems` is not "exactly the 5 design items" and has no
  default disciplines.**
  - Today it is `maxRows: 5` with no `minRows` and no defaults, and publishing with 4 systems →
    200.
  - **Fix:**
    - `minRows: 5`, `maxRows: 5`, `shot` unique (already done).
    - Default rows for the five systems with the spec mapping: HVAC→`hvac`,
      Fire→`fire-fighting`, Plumbing→`plumbing`, Power→`electrical`,
      Smart→`low-current` + `data-center`.
    - The `disciplines` options must show the same Arabic/English labels as `projects.scope`.
