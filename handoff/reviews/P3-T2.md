### Findings
- **R-1 [high] Fix the Figma mismatches in the table.** The Home navbar uses the **Light** theme and
  overlays the hero as in Figma. The footer matches the column positions, headings, CTA type,
  WhatsApp line and bottom bar.
- **R-2 [high] CMS nav items never get the active state or `aria-current`.**
  `src/components/Navbar.tsx:112` (`isNavItemActive`) ignores `link.internalRoute`, which is what the
  admin stores. Resolve the link through `resolveSafeCmsLinkData` first, and add a test.
- **R-3 [high, Phase 3 rule] An empty CMS shows invented content.**
  - `Navbar.tsx:170-173` and `Footer.tsx:118-121,253-256` fall back to dictionary nav/quick links,
    hard-coded routes, CTA labels and `/contact#quote`.
  - The footer CTA card renders with only `whatsapp` set.
  - **Fix:** no CMS data → no element.
- **R-4 [med] CMS fields are ignored.**
  - The footer column heading uses the dictionary instead of `navigation.footer[].title`.
  - Only `footer[0]` renders (`layout.tsx:195`).
  - `footerCta.whatsappLabel` is unused (`Footer.tsx:269`).
- **R-5 [med] Unknown social platforms get a wrong icon and label** (`Footer.tsx:165-167`,
  `idx % 5`): a YouTube URL rendered as WhatsApp. Map by platform; an unknown platform gets a
  generic link icon with its real name.
- **R-6 [med] "Privacy Policy" is an invented link to `/contact`** (`Footer.tsx:290-296`). Remove it,
  or render it only when the CMS provides a privacy link.
- **R-7 [med] The FAB pulse ring is off-centre in RTL.** `.pulseRing` uses `inset-inline-start:50%`
  with `translate(-50%)`: the ring centre is at x=-41 against the button's 56. Use `inset:0;
  margin:auto` (or a physical `left` with a justification comment).
- **R-8 [med, report vs reality] There is no "logical-property lint" in `eslint.config.mjs`.**
  ESLint does not lint CSS. Either add a real check (e.g. a script or stylelint rule in `pnpm
  lint` that fails on physical properties in public CSS) or remove the claim.
- **R-9 [med] Interaction tests are missing.** The P3-T2 tests use `renderToStaticMarkup` only.
  - Add behaviour tests for the focus trap, Esc, accordion toggle and switcher click (Testing
    Library, or Playwright run from `pnpm test:e2e`).
  - The card asks for them.
- **R-10 [low] Hit targets under 44 px at 390:** drawer links 36–38 px, social buttons 40×40, footer
  links 22 px.
- **R-11 [low, a11y]**
  - The switcher's `aria-label` must contain its visible text "ع" (WCAG 2.5.3).
  - The drawer has no slide animation; respect reduced motion.
- **R-12 [CTO decision] Contrast:** apply **docs/05-design.md §19**:
  - a navy focus ring on light backgrounds;
  - `--gold-700` for small gold text on light backgrounds;
  - log the computed ratios.
