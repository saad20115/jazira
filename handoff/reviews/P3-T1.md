### Findings
- **R-1 [critical, evidence fabrication] `console-ar.png` and `console-en.png` are not console
  captures.**
  - Each shows the page with a typed line pasted underneath: "[DevTools Console & CSP Inspector · /ar]
    … Console Errors: 0 | Hydration Warnings: 0 | CSP Violations: 0 …".
  - No DevTools panel is in the image. The text was written onto the page and presented as tool
    output.
  - This is the most serious kind of evidence problem: it is not a mistake in describing a real
    artefact; the artefact itself is manufactured. It is escalated to the owner.
  - **The live result happens to be true** (my reviewer saw a clean console). That does not make
    the evidence acceptable.
  - **New rule (README):** console, CSP and network evidence are machine-captured by a **committed
    script**, for example Playwright collecting `console`, `pageerror` and
    `securitypolicyviolation` events plus the request list into JSON. The script lives in
    `scripts/evidence/`, and the review re-runs it.
    - Screenshots are only for visuals.
    - Any text overlay on a screenshot is forbidden.
- **R-2 [major, evidence integrity]**
  - The report header and `citations-check.log` quote HEAD
    `6f4c896a5360a0d69b86c71f42c44f5cd1584f9e`. **That object does not exist.** The real commit is
    `6f4c896bb97f5fc86e6c33743f3f153ed9a86db0`.
  - `citations-check.log` prints a fresh-clone `pwd`, yet its body runs `check:citations D:\jazira`,
    so it ran in the working tree.
  - `install.log` shows "Already up to date … 1.7s", so `node_modules` existed and it was not a fresh
    clone.
  - Guard case A2 scanned a **hand-written** `chunks/throwaway-api-error.js` instead of a real
    `pnpm build`.
  - **Fix:**
    - regenerate all of r2 from a real fresh clone (empty directory, no copied `node_modules`);
    - HEAD comes from `git rev-parse HEAD` **inside** the clone, printed by the script, never typed;
    - run real builds for every guard case.
- **R-3 [major, security] The R-21 intent is still bypassable through allow-listed directories.**
  - `src/app/(payload)/x.ts` exports `async function db(){ return getPayload({config}) }`. A frontend
    page calls `(await db()).find(o)` with `overrideAccess:true`. Lint exits 0.
  - `import * as P from 'payload'; export const gp = P.getPayload` in `src/collections/` also passes.
  - **Fix:**
    - In `src/app/(frontend)/**` and `src/components/**`, ban imports of `@/app/(payload)/**`,
      `@/collections/**`, `@/globals/**`, `@/hooks/**`, `@/access/**`, `@/migrations/**`,
      `@/fields/**` and `@/security/**`, except an explicit list of pure modules if any (name each
      one).
    - Flag `getPayload` used as a value in any form.
    - Add a lint test for each proof above.
- **R-4 [minor] The client-bundle library markers (§9) do not work.**
  - They are module-path strings, which Turbopack removes.
  - A client component importing `APIError` from `payload` builds green and adds a 33.6 KB chunk.
  - **Fix:** use content markers that survive minification, or a module-graph / manifest check.
    Prove both directions with real builds.
- **R-5 [minor, Phase 3 rule] Public pages fall back to specimen marketing copy.**

  - The dictionary holds invented numbers (`250+`, `120+`).
  - **Fix:** empty CMS → the section is hidden. Sample copy lives only in specimen data. No business
    numbers in code.
- **R-6 [minor] `no-jsx-string-literals` is easy to bypass.** Ternaries, `||` / `??`, concatenation,
