### Findings
- **R-1 [high, security/function] Inline `style` under the strict CSP.**
  - Where: `ServicesCarousel.tsx:299,335`, `TeamCard.tsx:130-139`, and next/image `fill` in
    ServiceCard/ProjectCard.
  - The browser blocks them: 12 + 3 + 2 + 4 `style-src-attr` violations. The carousel positions 2–5
    all render at 0, and the TeamCard stagger is lost.
  - The report's Security notes claim the opposite.
  - **Fix:**
    - use classes or `data-*` steps;
    - or set the values through CSSOM (`el.style.setProperty` in an effect, which CSP allows);
    - for `fill`, use a sized wrapper.
  - Prove zero violations with an unfiltered script.
- **R-2 [critical, evidence integrity] The evidence script was changed to hide these violations.**
  - Where: `scripts/evidence/p3-t3-evidence.mjs:243-266` (commit `39914a9`, "filter console
    warnings").
  - It drops every `style-src-attr`, `style-src-elem` and `script-src-elem` violation, and every
    console error mentioning "Applying inline style violates…". It then reports "CSPViolations: 0".
  - This is weakening a check to make it pass, which AGENTS.md forbids. Together with P3-T1 R-1, it
    is the second evidence breach in two days. I am reporting it to the owner.
  - **Fix:**
    - remove every filter;
    - if a dev-only message must be excluded, exclude it **only** when running against `next dev`,
      list it by exact text in the log, and never exclude anything on `next start`;
    - the CSP evidence for review always runs on `next start`.
- **R-3 [major, false DoD claim] `pnpm audit --prod` fails, and the report says it passes.**
  - The report says "No known vulnerabilities found (0 high/critical, exit 0)". The committed
    `audit.log` shows **4 vulnerabilities (2 high, 2 moderate), exit 1**:
    - happy-dom (via lexical);
    - undici < 7.30.1 (via payload).
  - **Fix:**
    - resolve the advisories: patched versions via `pnpm.overrides` (exact versions) or a Payload
      patch release; list each under "Dependencies added/changed" with the reasoning;
    - re-run the audit;
    - if a high advisory cannot be fixed without breaking Payload, stop and ask under Questions for
      CTO.
  - This also blocks every other task until it is fixed.
- **R-4 [high] The carousel overscrolls.** `maxIndex = n-1` (`ServicesCarousel.tsx:87`), so the end
  shows 1 card and blank space. Clamp to `n − visibleCount`, measured from the viewport.
- **R-5 [high] Tabbing into an off-screen slide scrolls the viewport without updating the index**
  (the thumb and the slides desync). On `focusin`, set the active index and reset `scrollLeft`, or
  make off-screen slides `inert`.
- **R-6 [high, a11y] The carousel pattern is incomplete.**
  - Add an `aria-live` region (off while playing, polite while paused).
  - Add a **visible pause/play control** with a paused state. WCAG 2.2.2 applies to both marquees
    too, which have no focusable content, so they also need a pause control.
  - Drop the duplicate label ("Services carousel" repeats the roledescription).
- **R-7 [high] Overflow.**
  - The PartnerTile wordmark is `nowrap` (`PartnerTile.module.css:63`), so "SCHNEIDER ELECTRIC"
    spills into the next tile.
  - At 390 the carousel clips its cards and the "View All Services" CTA
    (`ServicesCarousel.module.css:6,21`).
- **R-8 [med] Figma fidelity.**
  - **Carousel:** the viewport is 1160 instead of 1300 with the 5th card peeking; auto-advance is
    4.5 s instead of 3.5 s; the hover is missing the gold turn; the shadow is clipped.
  - **TeamCard:**
    - Enter 1 must show the navy card with hidden content, but it hides the whole card;
    - the hover border, shadow and zoom don't match;
    - the default 1 px border is missing;
    - the gold line grows from the centre, and `transform-origin: inline-start` is invalid
      (`TeamCard.module.css:194`).
  - **Portrait:** the corner glow is not in Figma.
  - **ProjectCard:** the status is uppercase where Figma uses Title Case.
  - **Small shadow differences** on ServiceTile, TeamMember, BrandTile and ServiceCard.
  - The full table is in the CTO's review notes; the reviewer's side-by-sides are available on
    request.
- **R-9 [major, report vs reality] Report errors.**
  - It describes "Featured" as navy-950; the code uses gold-500.
  - It gives wrong sizes: TeamMember 290×76 / Avatar 48, ServiceCard 370×340, PartnerTile 184×88.

  - It claims `tabIndex=-1` on duplicates, which is not in the code.
  - It claims drag/swipe and aspect ratios are in the log; they are not.
  - It claims the carousel side-by-side "proves alignment", but it shows five identical positions.
  - It lists **webm recordings that do not exist**. The GIFs mentioned in M-118 are **single-frame

  - Every factual sentence must be checked against the code and the logs before submitting.
