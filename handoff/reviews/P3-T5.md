## Decision during step 3 (2026-10-25): KTX2 transcoder vs CSP → option (A), H3b
- **Verified by the CTO:**
  - `node_modules/three/examples/jsm/libs/basis/basis_transcoder.js` (`8478b5b6…`) calls
    `newFunc(Function, args)`;
  - `KTX2Loader` creates its workers with `new Worker(URL.createObjectURL(new Blob(...)))`, so they
    inherit the page CSP.
- **Decision (`docs/03-security.md` H3b):** a same-origin, hash-pinned worker file with its own narrow
  CSP. The page CSP gets no `'unsafe-eval'`. The `next.config.ts` single header rule is added to E1.
- **Proof required:**
  - the worker response carries exactly **one** CSP header (the proxy's page CSP must not also apply
    to that path);
  - the page responses are unchanged;
  - 0 violations;
  - a negative test: the worker CSP header removed → the viewer falls back to stills, with no broken
    canvas.
- The `inlineBasisuPlugin` (no `blob:` for embedded images) is accepted in principle; it gets a unit
  test that it handles only `KHR_texture_basisu`, with the same sampler and flipY as three's.
- **Follow-up:** a transcoder rebuilt with `-sDYNAMIC_EXECUTION=0` via the 3D lead, to reach zero
  `'unsafe-eval'` anywhere.

## Decision (2026-10-25): accordion rest state and entering
- **Rest state:** Figma's HVAC is expanded at rest. Nothing is entered on load, and there is no hash.
- **Entering a system:**
  - opening a collapsed item enters it (§5);
  - every expanded panel has a "Show in 3D" button, which is how the pre-expanded HVAC is entered;
    in the stills tier it shows that system's end still;
  - a `#systems-<id>` hash on load enters that system and expands its item.
- **Collapsing an expanded header** collapses it; if that system is entered, it also exits. There is
  never a "click twice to enter".
